## 🎯 Актуальность

Тимлидам, CTO, maintainers и владельцам платформ сложно быстро понять состояние репозитория:

- данные разбросаны между git-историей, CI, README, issues, merge requests, security-сканированием и review-комментариями;
- нужен единый слой аналитики, который превращает технические сигналы в понятную оценку проекта.

&nbsp;
## 🧩 Описание задачи

Разработать сервис, который оценивает **здоровье открытых репозиториев**, уже находящихся в SourceCraft.

**Обязательная часть:**
- сервис должен показывать **Repo Health Score 0–100**, объяснять оценку и давать конкретные рекомендации по улучшению проекта;
- простая страница рейтинга открытых репозиториев SourceCraft.

**Часть со звёздочкой:**
- расширенный публичный рейтинг открытых репозиториев SourceCraft;
- дополнительные возможности сервиса оценки здоровья.

&nbsp;
## 📦 Ресурсы

- Открытые репозитории SourceCraft;
- Тестовые репозитории организаторов;
- Git-история и метаданные SourceCraft;
- Результаты security-сканирования AppSec SourceCraft;
- CI-конфиги и статусы пайплайнов SourceCraft;
- Данные по лайкам репозиториев SourceCraft;
- Метаданные issues, merge requests, contributors и релизов.

&nbsp;
## 🚀 Описание итогового продукта

Веб-сервис оценки здоровья открытых репозиториев SourceCraft, который:

- автоматически рассчитывает интегральный показатель **Repo Health Score**;
- формирует рекомендации по улучшению качества проекта;
- предоставляет аналитический дашборд репозитория;
- предоставляет публичный рейтинг открытых репозиториев.
